# COMP-002 Terminal Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a concise two-case deterministic terminal demo for the existing COMP-002 contract.

**Architecture:** Add one COMP-002-only ReferenceAdapter evidence mode and a presentation module
that runs both cases through Runner, round-trips evidence in memory, and offline-rescores it. Keep
all scoring and scenario semantics in their existing owners.

**Tech Stack:** Python 3.11, pytest, existing CoderPolice Runner/oracle/evidence machinery.

## Global Constraints

- Do not change the COMP-002 scenario, completion oracles, or generic classifier.
- Do not run or claim evidence about a real coding-agent host.
- Add no dependency and leave no evidence file behind.
- Use plain, short, cross-platform terminal output with no ANSI, emoji, or em dash.
