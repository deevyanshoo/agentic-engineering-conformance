# v0.1.0-alpha.1 release notes (draft)

Status: draft. No tag, GitHub release, package publication, or public visibility change has been authorized or created.

## Alpha scope

This research alpha packages this project's initial vendor-neutral reference vertical slice for testing engineering-control guarantees around coding-agent stacks. It includes:

- six provisional domains: AUTH, MUT, COMP, REV, INV, and REC;
- six deterministic synthetic reference scenarios with separate functional and control outcomes;
- all six run classifications, guarded-versus-behavioral pass semantics, explicit evidence provenance, and stored-evidence rescoring;
- the common adapter interface plus Codex and Claude Code AUTH-001 integrations;
- digest-bound neutral Windows Task Scheduler experiment execution;
- a no-conflict calibration condition and paired aggregate interpretation; and
- public contribution, security, evidence/privacy, licensing, claims, and prior-art guidance.

The Python project version is `0.1.0a1`; the proposed human-facing Git tag is `v0.1.0-alpha.1`.

## AUTH history and current semantics

AUTH-001 v1 remains immutable for historical replay. AUTH-001 v2 preserves stale selection `A` as a control failure, identifies current behavior `B` as a behavioral pass unless a guard is independently observed, and represents no decision (`UNSET`) as functional failure with control `INCONCLUSIVE`. Calibration uses the same useful mutation without stale conflict and is not an AUTH conformance result.

The M5 twelve-slot batch remains historical and terminally invalid before model launch. A distinct M6 successor executed all twelve paired slots at one bound revision. Its sanitized report records exact run-specific outcomes and limitations. N=3 per condition supports no ranking or statistical conclusion.

## Verification state

The private launch candidate passed Ruff formatting (121 files) and lint, strict mypy (27 source files), 243 deterministic tests including schemas/contracts, complete branch-range diff checks, secret/proprietary scans, and clean-clone reproduction. The exact completion-record SHA and its final recheck are supplied in the M6 handoff before publication authorization is requested.

Hosted CI success is not claimed at draft time because GitHub Actions is externally unavailable before repository steps while private. See the [CI strategy](../ci.md).

## Limitations and non-claims

- The six-domain taxonomy and real-host AUTH construct validity remain experimental.
- Real adapters currently cover AUTH-001, not all six domains.
- The neutral worker is Windows-specific and does not create a sterile environment.
- Small historical and launch-validation samples are not comparative performance evidence.
- This is not security certification, a complete agent-safety framework, or a production guarantee.
- No novelty or priority claim is made for the underlying workflow, evidence, review, DAG, invalidation, tracing, or orchestration concepts.
