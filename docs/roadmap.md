# Roadmap

The roadmap is evidence-led and does not promise dates.

## v0.1 alpha

- deterministic reference framework and six provisional domains;
- six synthetic scenarios and every run classification;
- stored-evidence rescoring and scenario versioning;
- AUTH-001 Codex and Claude Code adapters;
- no-conflict calibration and paired interpretation;
- experimental neutral current-user Windows Task Scheduler worker; and
- public contribution, evidence, security, and claim boundaries.

`v0.1.0-alpha.1` remains the historical first public release under the technical working title **Agentic Engineering Conformance**. The CoderPolice brand transition is a naming/public-surface change only and does not alter benchmark semantics or historical evidence.

## Evidence required before expansion

- establish whether AUTH-001 v2 and calibration are interpretable across recorded host configurations;
- exercise and review public installation/contribution paths;
- validate portability of neutral execution beyond one Windows scheduler context;
- determine statistical trial policies before any comparative reporting; and
- earn evidence before adding another real-host scenario or adapter.

## Explicitly not planned for the alpha

No dashboard, hosted service, database, leaderboard, composite score, workflow runtime, task manager, editor extension, GitHub App, model router, or additional host is part of the current v0.1 alpha scope.
